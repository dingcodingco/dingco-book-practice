# 오후세시 베이커리 블로그 → 인스타그램 + 뉴스레터

## 누가 쓰나
오후세시 베이커리를 운영하는 사장 부부. 개발이나 마케팅 용어 없이 바로 복사해서 쓸 수 있는 결과물을 원합니다.

## 입력
블로그 글 한 편 (붙여넣은 글, 첨부 파일, 링크 중 하나). 링크면 먼저 글을 읽어 옵니다.

## 진행 순서
1. 블로그 글을 끝까지 읽고 핵심(어떤 빵/소식인지, 왜 특별한지, 손님이 할 일)을 뽑습니다.
2. 아래 두 결과물을 한 번에 씁니다.
3. 사실 확인 규칙을 지킵니다 (아래 참고).
4. 비워 둔 항목이 있으면 맨 끝에 질문으로 묶어 물어봅니다.

## 결과물 1: 인스타그램 게시글
- 본문은 5줄 이내 (해시태그 줄은 제외).
- 마지막 본문 줄은 반드시 '자세한 이야기는 블로그에서' 안내 문장.
- 그 아래 해시태그 정확히 5개, 한 줄에 띄어쓰기로 구분.
- 따뜻하고 짧은 가게 말투. 이모지는 줄마다 많아야 1개.

## 결과물 2: 뉴스레터 소개 글
- 제목 한 줄.
- 본문 정확히 3문장.
- 전부 존댓말(~습니다/~해요 중 한 가지로 통일, 기본은 ~습니다).

## 사실 확인 규칙 (가장 중요)
- 블로그 글에 없는 가격, 시간(영업시간·출시 시각·판매 기간), 수량, 날짜는 절대 지어내지 않습니다.
- 필요한 자리에는 `[가격 확인 필요]`, `[시간 확인 필요]`처럼 빈칸 표시를 남깁니다.
- 블로그에 있는 숫자는 그대로 옮기고 바꾸지 않습니다.

## 출력 형식
```
📸 인스타그램
(본문 최대 5줄)
자세한 이야기는 블로그에서 👉
#해시태그1 #해시태그2 #해시태그3 #해시태그4 #해시태그5

✉️ 뉴스레터
제목: ...
(문장 1) (문장 2) (문장 3)

❓ 확인이 필요해요
- 가격: 블로그에 없어서 비워 두었어요. 얼마인가요?
- 시간: ...
```
비워 둔 항목이 없으면 '확인이 필요해요' 부분은 빼도 됩니다.

## 마무리 점검
- 인스타 본문 5줄 이내인가? 해시태그 정확히 5개인가? 마지막 줄 블로그 안내가 있는가?
- 뉴스레터 제목 1줄 + 본문 3문장 + 존댓말인가?
- 블로그에 없는 가격·시간을 쓰지 않았는가?
